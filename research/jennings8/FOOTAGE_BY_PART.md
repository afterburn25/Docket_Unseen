# Jennings 8 — Archival Footage by Series Part

## Goal

Every part should use real archival material wherever it adds factual value.

Visual hierarchy:
1. **Primary / contemporaneous footage**
2. **Official records / documents**
3. **Archival family / journalist interviews**
4. **Maps / graphics**
5. **Reconstructions only where real material does not exist**

Do not use copyrighted footage as generic filler. Every clip must support a specific point.

# Archival-use rule

Before final edit, every third-party clip must have one of:
- licensed/permission status;
- public-domain status;
- public-record status plus copyright assessment;
- documented fair-use rationale for short transformative excerpt.

Maintain a clip log with:
- source;
- owner;
- timestamp;
- duration;
- purpose;
- transformation/commentary;
- credit text.
