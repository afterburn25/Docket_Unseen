# Jennings 8 — Case Number / Record Identifier Index

## Purpose

This file collects exact case numbers, docket numbers, report numbers, and archival identifiers that can unlock primary records.

A citation by an advocacy filing or journalist does **not** make every allegation in that source proven. The identifiers themselves are useful because they point to underlying police, court, ethics, or civil records.

## Why the multi-agency identifiers matter

The repeated trio:
- JPD **K-06184-08**
- JDPSO **2008110110**
- LSP **09-576**

may be especially valuable because the same identifiers appear in PJI footnotes supporting multiple later claims about the eight-case task force.

Questions for agencies:
1. What incident/victim does each number correspond to?
2. Are they umbrella task-force cases or victim-specific cases?
3. Which reports/exhibits are associated?
4. Which pages are publicly releasable?
5. Do the files contain CI/informant records that are exempt?
6. Do they contain Brittney/Tracee/Terrie/Frankie witness material?
7. Were these files transferred into the current cold-case review?

## Record-request rule

Always include exact case number where known.

Example:

> Please provide all publicly releasable records, indexes, public reports, and final-disposition material associated with Louisiana State Police Case #WDD004505 concerning the April 20, 2005 police-involved shooting of Leonard Crochet.

This is much stronger than asking:
> Send everything about the Jennings 8.
